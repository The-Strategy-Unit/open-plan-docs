# Glossary

Permitted abbreviations:

* OCC = occupancy
* UTIL = utilisation
* LOS = length of stay
* DNA = did not attend

* AE = Accident and Emergency
* OP = outpatient
* SDEC = Same Day Emergency Care
* CC = critical care

* PROC = procedure
* INT = interventional
* IR = interventional radiology
* CATH = catheter
* LAB = laboratory
* RESUS = resuscitation
