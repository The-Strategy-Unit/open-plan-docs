# Developer Information

All the code for the OpenPlan Capacity Conversion Tool is open source.

You can view the code (written in Python) for the Tool here:

- [Conversion logic](https://github.com/The-Strategy-Unit/nhp_capacity_conversion_logic)
  
- [Functional area mapping](https://github.com/The-Strategy-Unit/nhp_functional_area_mapping)

And the code for this documentation site (which is built using 
[Zensical](https://zensical.org/)) can be seen here:

- [Documentation](https://github.com/The-Strategy-Unit/open-plan-docs)

If you have corrections, suggestions or bug fixes and you have a 
[GitHub account](https://github.com/) you can add an 
[issue](https://github.com/features/issues) or raise a 
[pull request](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/about-pull-requests) against any of the code repositories associated with the tool. 
  
Feel free to view our [open source policy](https://connect.strategyunitwm.nhs.uk/open-source-policy/).
