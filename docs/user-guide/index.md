## What if I have more questions/comments/suggestions?
 
:lucide-message-circle-more: You can click the 'Give feedback' button at any time on the interface or on
this website to let us know what you like/don't like or suggest for future improvements.

:lucide-mail: You can email the [data science team](mailto:mlcsu.su.datascience@nhs.net)

:lucide-code-xml: If you have a [GitHub account](https://github.com/) you can add an [issue](https://github.com/features/issues) or raise a [pull request](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/about-pull-requests) against any of the code repositories associated with the tool. These include:
 
- https://github.com/The-Strategy-Unit/open-plan-docs
- https://github.com/The-Strategy-Unit/nhp_capacity_conversion_logic
- https://github.com/The-Strategy-Unit/nhp_functional_area_mapping
