### What inputs are needed from me?

- the name and 'datetime' of an OpenPlan (formerly 'NHP') model scenario you have 
created using version 4.4 or later of the [OpenPlan demand model](https://connect.strategyunitwm.nhs.uk/nhp/project_information/).

### What does the tool produce?

An Excel workbook containing the mean and 80% confidence intervals of estimated
capacity requirements across all the standard groupings (see [here](/docs/reference/functional-area-catalogue.md) for details) 
will be available for download. 
This file will also contain the values of all [assumptions](/docs/reference/assumptions-register.md)
used in the conversion.

### How to use the tool
Select a model scenario from the OpenPlan [interface app](<link>).

Click 'Convert this scenario'.

You will recieve an email (to the email address you used to register with our
Connect server) to notify you when you can return to the interface to download your
results file.
