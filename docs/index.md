# Welcome!
 
This site documents the **OpenPlan Hospital Capacity Model**, a modular
framework for converting healthcare activity into estimates of capacity requirements.
 
:lucide-rocket: If you want to know how to use the model, see our [quick start guide](user-guide/quick-start).
 
:lucide-boxes: For a simple overview of how the model works, please visit the [methodology](user-guide/methodology) page.
 
:lucide-sigma: If you would like the detail on how the model works, have a look at the
[technical information](technical-information).

Have a question or suggestion? Use **Give feedback** to contact us about the model.
